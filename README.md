## 🚀 Getting Started

### Prerequisites

- Python 3.7 or higher
- Basic command line knowledge

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/band-name-generator.git
   cd band-name-generator
   ```

2. **Run the script**
   ```bash
   python Proj1_BandNameGenerator.py
   ```

## 🎮 How to Use

1. Run the script
2. Enter your city name when prompted
3. Enter your pet's name
4. Get your unique band name!

Example:
```bash
$ python Proj1_BandNameGenerator.py
Welcome to the Band Name Generator.
What's the name of the city you grew up in?
Electric
What's your pet's name?
Penguin
Your band name could be Electric Penguin
```

```plaintext
Welcome to the Band Name Generator.
What's the name of the city you grew up in?
Neon
What's your pet's name?
Dragon
Your band name could be Neon Dragon
```

## 🧠 How It Works

The script uses simple string concatenation to combine two user inputs:
1. The name of the city you grew up in
2. The name of your pet

The magic happens with this simple line of code:
```python
print("Your band name could be " + street + " " + pet)
```
